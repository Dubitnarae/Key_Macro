# 키보드·마우스 매크로

Windows 용 키보드·마우스 매크로 프로그램. 개발자: KIM YEONGDO

[Releases](https://github.com/Dubitnarae/Key_Macro/releases/latest) 에서 `Key_Macro.exe` 를 받아 실행합니다. 시작할 때 새 버전을 확인해 자동으로 업데이트합니다.

- `기록` → F9 로 시작/끝 → 이름과 시작 단축키 지정
- F8: 매크로 실행 가능 ↔ 중단 전환(실행 중이면 모두 멈춤)
- F7: 마우스·색 입력 창에서 현재 위치와 색 가져오기
- 매크로는 exe 옆 `매크로.json` 에 저장됩니다.

변경 내용은 [CHANGELOG.md](CHANGELOG.md) 참고.
